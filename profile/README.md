# ECAT-ICAT-Formal

**ECAT-ICAT-Formal develops the formal, executable, and reviewable surfaces for ECAT/ICAT research.**

The organization separates mathematical/reference material, machine verification, organizational validation, integration bridges, sandbox work, and publication so claims can be inspected without conflating any one surface with authority.

## What belongs here

Representative repositories include:

- **reference-library** — formal definitions and source references;
- **lean-verifier** — machine-checkable verification work;
- **validator** — organization-level structural and semantic checks;
- **docs** — formal documentation;
- **sandbox** — bounded experimentation;
- **hybrid-bridge** — integration with adjacent formal/runtime systems;
- **publisher** — bounded publication output;
- **telemetry** — observation and validation evidence.

## Boundary

Verification, validation, publication, or repository presence does not independently grant execution authority or prove claims outside the explicitly checked scope.

ECAT/ICAT results are intended to compose with broader admissibility and transition research while preserving the distinction between formal evidence, runtime execution, and operational authority.
